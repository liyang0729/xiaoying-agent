# 04 AI 辅助使用记录

## 使用范围

开发过程使用 AI 编码助手（Cursor + GLM）辅助完成以下内容：

1. **需求拆解与方案设计**：讨论了题目要求、验收点映射、技术取舍
   （原生实现 vs 框架、关键词检索 vs 向量检索）；
2. **代码起草**：`src/tools.py`、`src/llm.py`、`src/agent.py`、`src/cli.py`、
   `tests/` 全部由 AI 起草，本人逐段理解讲解内容；
3. **文档起草**：`docs/` 与 README 由 AI 起草初稿，本人核对与实际运行
   结果的一致性；
4. **examples/ 清洗**：本人运行得到的终端原始记录（输出.txt）由 AI
   清洗归档为 7 个示例文件。
