# 示例 7：步数上限（unfinished 状态）

- 输入：`python src/cli.py -q "报销期限多久" --max-steps 1`
- 任务状态：unfinished（明确的未完成状态，题目硬性要求）
- 对应验收点：执行步数上限

## 输出

```
任务状态: unfinished
资料缺口: 达到最大步数 1，任务未完成

[step 1] 动作: search
  参数: {"query": "报销期限"}
  决策依据: 用户询问报销期限，需检索知识库相关制度
  结果摘要: 检索命中 3 篇：D01, D02, D04
```

## 简评

- `--max-steps 1` 使循环只允许执行 1 步。模型完成 search 后即达上限，
  系统返回明确的 `unfinished` 状态并在缺口中说明原因，而不是继续硬跑或给出无依据的回答。
- 默认上限为 8 步（`agent.py` 中 `run_agent` 的 `max_steps` 参数，可用 CLI 覆盖）。
- 引用校验、解析纠错等通路同样消耗步数，因此纠错风暴也不可能突破上限。
